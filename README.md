# Florăria Crinul Regal - Client Website

This is a complete **e-commerce flower shop website** built for a real client, _Florăria Crinul Regal_, based in Romania. The site is now fully deployed and live at:

**[https://florariacrinulregal.ro](https://florariacrinulregal.ro)**

---

## Overview

The website provides a modern, elegant, and mobile-friendly interface for showcasing flower bouquets, arrangements, and gifts. The platform supports:

-  Multiple categories (e.g., Buchete, Plante, Cadouri, Nunți)
-  Live product search
-  Image gallery with smooth popup display
-  Admin panel with secure login and product management
-  Full responsiveness across devices

---

## Tech Stack

| Layer         | Technology               |
|---------------|---------------------------|
| Frontend      | React + Tailwind CSS      |
| Backend       | Firebase Firestore        |
| Auth & Hosting| Firebase Authentication + Hosting |
| Storage       | Firebase Storage          |
| Deployment    | Firebase CLI              |

---

##  Key Features

- Admin dashboard with:
  - Product management (Add/Edit/Delete)
  - Image upload to Firebase Storage
  - Homepage, Portfolio, and Hero image control
- Client-side routing with React Router
- Clean and responsive layout for mobile & desktop
- Optimized for Google indexing with proper metadata and sitemap

---

## Deployment
